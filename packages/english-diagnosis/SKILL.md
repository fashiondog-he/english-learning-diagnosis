# 中式英语深层诊断（专业教师工作流）

本技能把专业写作教师的固定流程写成可执行步骤。**每步都有产物，任何一步的产物不成立就停止，不要往下编。**

## 何时用

- 用户粘贴一段**英文**写作（≥3 句），并问"哪里不地道 / 为什么像中式英语 / 怎么改"。
- 用户已有一版改写，想对比迁移痕迹是否减少。

**何时不用**：只问单词意思、只要翻译、要评分/等级、要"能不能过考试"——直接说明本工具不做这些。

## 工作流（按序执行，不要跳步）

1. **确认输入边界**。只接受工具参数里的英文文本。用户若给文件路径、链接、录音，请其粘贴文本；不要自己去读文件或抓网页。
2. **先看整体，不先挑错**。默读一遍，用一句话写下"这段文字想论证什么"。若写不出来，说明语篇层面已经断了——直接向用户说明，优先处理结构而不是句子。
3. **调用 `english_diagnose`**（`focus: all`）。拿到 `findings`。
4. **按类归因**，把 findings 分成三组：
   - `syntax`：句法层迁移（冠词、长句并联）
   - `collocation`：词汇搭配直译
   - `discourse`：语篇习惯（模板开头、连接词堆叠、泛指 you）
5. **验证证据**。逐条回看 `span.quote` 是否真的在原文中、是否被误判。**证据对不上就丢弃该条**，不要为了凑数保留。
6. **只讲 3 条以内**。按 `confidence` 降序，选与用户目标最相关的 ≤3 条展开：现象 → 为什么是迁移 → 一个可立刻做的微练习（用 `nextStep`）。
7. **给一条重写路径**，不是给一篇范文。让用户自己改；改完可以再调一次工具对比 findings 数量。
8. **收尾**：说明本次未覆盖的规则与局限（读 `limits`），并问用户要不要针对某一条做专项练习。

## 终止条件（满足任一即停）

- 文本 < 3 句，或明显不是英语写作（代码、单词表、翻译请求）→ 说明不适用，停止。
- 输入被拒（非空校验 / 超过 20000 字符）→ 请用户分段，停止。
- `findings` 为空 → 明确说"当前 9 条规则未命中，这不等于没有问题"，停止，不要编造问题。
- 用户要评分、等级、是否合格、能否通过考试 → 拒绝并说明边界，停止。
- 证据与原文对不上 → 丢弃该条；若全部对不上，停止并说明规则集不可靠。

## 局限性声明（必须让用户看到）

- 本工具是**基于有限规则的诊断提示**，不替代教师评估。
- 输出仅用于学习路径推荐，**不可用于选拔、惩罚或任何法律决定**。
- 改写建议为 AI 生成，用户应自行判断是否采纳。
- 当前为 9 条确定性规则（`l1-transfer-0.3.0`），覆盖范围有限；未命中不代表写作没有问题。
- 插件不保存原文；DSH 会话日志仍会记录工具入参与结果（本机文件）。

## 输出纪律

- 不用"等级""分数""不合格""扣分"这类可被用于惩罚或选拔的表述。
- 每条结论必须能指回 `evidence.quote` 与 `ruleRef`；指不回就不说。
- 一次最多展开 3 条，避免把诊断变成批改清单。
